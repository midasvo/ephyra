# Home and library

Status: built across phone/tablet and Android TV (shared ViewModels in `modes/film`, separate layouts in `app/phone` and `app/tv`), including customisable Home rows, cold-start Home cache, indexed A–Z library paging, Room download fallbacks on phone, detail extras/related rows, and optional MDBList external ratings. As of 2026-11-25 (`main` at `c41b7f7dc`).

## Start here

- Shared ViewModels and domain logic live in `modes/film/`: `HomeViewModel` (`home/`), `LibraryViewModel` (`library/`), `MediaViewModel` (`media/`), `FavoritesViewModel` (`favorites/`), `CollectionViewModel` (`collection/`), `MovieViewModel` (`movie/`), `ShowViewModel` (`show/`), `SeasonViewModel` (`season/`), `EpisodeViewModel` (`episode/`), `PersonViewModel` (`person/`), and `HomeRowsViewModel` (`homerows/`).
- Phone/tablet screens and shared film components live in `app/phone/.../presentation/film/` (`HomeScreen`, `LibraryScreen`, `MediaScreen`, `FavoritesScreen`, `CollectionScreen`, `MovieScreen`, `ShowScreen`, `SeasonScreen`, `EpisodeScreen`, `PersonScreen`, `ItemButtonsBar`, `LetterFastScroller`, `ExternalRatingsRow`, plus wide layouts in `MovieWideLayout`, `ShowWideLayout`, `SeasonWideLayout`).
- TV CE screens live in `app/tv/.../ce/presentation/film/` (`HomeScreen`, `LibraryScreen`, `FavoritesScreen`, `CollectionScreen`, `MovieScreen`, `ShowScreen`, `SeasonScreen`, `PersonScreen`, `DetailMetadata`).
- Data path: ViewModels read repository role interfaces in `application/.../repository/` (`ItemCatalog`, `ItemLists`, `ItemExtras`, bound to `MediaRepositoryImpl`) over domain ports in `domain/.../domain/ports/` (`ItemPort`, `ItemListPort`, `ItemExtrasPort`), implemented by `JellyfinCatalog` in `server/jellyfin/`.
- Optional external ratings on movie and show screens go through `ExternalRatingsLoader` (`modes/film/`) and `ExternalRatings` / `ExternalRatingsService` (`application/.../ratings/`), backed by `ratings/mdblist/` (`MdbListClient`, `FileRatingsCache`).
- Test fast: `./gradlew :modes:film:testDebugUnitTest`.

## What it does

### Home

`HomeViewModel` loads the active server name and current user, then fetches Suggestions (`getSuggestions`), Continue Watching (`getResumeItems`), Next Up (`getNextUp`), and each visible library's Latest row (`getLatestMedia`) concurrently inside `coroutineScope` (`HomeViewModel.runLoad`). Each library's Latest row updates `HomeState.views` as soon as it completes (`loadLatest`) so a slow library does not hold back the rest ([#251](https://github.com/midasvo/ephyra/issues/251)).

Row visibility and order are per user and server via `HomeRows` and `HomeRowsStore` (`HomeRowsProfile`, stored under `pref_ce_home_rows_<serverId>_<userId>`, falling back to `LegacyHomeSwitches` until changed) and edited in `HomeRowsViewModel` ([#142](https://github.com/midasvo/ephyra/issues/142), [#431](https://github.com/midasvo/ephyra/issues/431)). `HomeState.orderedRows()` returns the loaded sections in `rowOrder`. When `appPreferences.homeCache` is enabled, `HomeCache` stores the latest rows per server and user in `filesDir/home-cache/<serverId>_<userId>.json` (`VERSION = 2`) so a cold start renders them immediately before the network refresh arrives ([#251](https://github.com/midasvo/ephyra/issues/251), [#608](https://github.com/midasvo/ephyra/issues/608)).

`HomeViewModel.followCurrentUser()` observes `observeCurrentServerId()` and `observeCurrentUser()`. On a user switch, `onCurrentUser` increments `generation` under `switchLock`, invalidates `ReloadPolicy`, cancels the previous `loadJob`, resets state, and waits up to `CLIENT_SWITCH_WAIT_MS` (`3_000L` ms) for `CurrentAccount.getUserId()` to match (`clientActsFor`). In the UI, `HomeState.shownTo(userId)` and `SessionUser.recheck()` prevent rendering a single frame of the previous user's rows ([#810](https://github.com/midasvo/ephyra/issues/810), [#872](https://github.com/midasvo/ephyra/issues/872)). Phone `HomeScreen` reloads via `ReloadOnResume` + `ReloadPolicy` (`DEFAULT_MAX_AGE_MS = 60_000L` ms plus `DataChangeEvents`), showing `ServerOrErrorCard` beneath `HomeHeader` when rows are already on screen ([#392](https://github.com/midasvo/ephyra/issues/392), [#571](https://github.com/midasvo/ephyra/issues/571), [#775](https://github.com/midasvo/ephyra/issues/775)) or `ErrorState` / `EmptyState` when empty. TV `HomeScreen` adds a backdrop hero tracking focused cards (`HeroFocus`) and opens episodes into their season ([#130](https://github.com/midasvo/ephyra/issues/130)).

### Libraries, My media, Collections, and Favourites

`MediaViewModel` loads libraries (`ItemLists.getLibraries()`) with `ReloadPolicy`, user-switch clearing (`shownTo`), and `ServerAwayReload` so phone `MediaScreen` switches to Room's synthetic Movies and Shows libraries while the server is unreachable ([#775](https://github.com/midasvo/ephyra/issues/775), [#781](https://github.com/midasvo/ephyra/issues/781)).

`LibraryViewModel` maps `CollectionType` (`Movies`, `TvShows`, `BoxSets`, `MusicVideos`, `HomeVideos`, `Mixed`, `Folders`) to `ItemKind` filters and `recursive` flags (`HomeVideos`, `Mixed`, and `Folders` include `ItemKind.FOLDER` and query non-recursively; [#671](https://github.com/midasvo/ephyra/issues/671)). Both phone and TV `LibraryScreen` pass `indexed = true` to `LibraryViewModel.setup`, which builds `indexedItemsPager` (`IndexedItemsPagingSource`, `LIBRARY_PAGE_SIZE = 40`, `enablePlaceholders = true`, `jumpThreshold = 120`) over `ItemLists.getItemsPage(..., includeTotal = true)` on the first page; unindexed callers use `itemsPager` (`ItemsPagingSource`). When sorted by `SortBy.NAME` on an indexed grid, `loadLetterIndex` queries 26 `ItemLists.getItemCount(..., nameLessThan = boundary)` counts in parallel (`LetterIndex.BOUNDARIES`, `'a'..'z'`) after the first page reports `total`, feeding phone `LetterFastScroller` and TV's A–Z jump bar ([#135](https://github.com/midasvo/ephyra/issues/135), [#672](https://github.com/midasvo/ephyra/issues/672)). `LibraryViewModel.loadItemsIfNeeded()` caches a `LoadKey(parentId, libraryType, indexed)` so Back navigation keeps the loaded grid while process death reloads it ([#371](https://github.com/midasvo/ephyra/issues/371)).

`CollectionViewModel` loads a box set (`ItemLists.getItems` sorted by `SortBy.RELEASE_DATE`) and splits items into `Movie`, `Show`, and `Episode` `CollectionSection` groups. `FavoritesViewModel` fetches `ItemLists.getFavoriteItems()`, groups by kind, guards user switches (`shownTo`), and integrates with `ServerAwayReload` and `ReloadAfterSync` on phone ([#775](https://github.com/midasvo/ephyra/issues/775), [#782](https://github.com/midasvo/ephyra/issues/782), [#866](https://github.com/midasvo/ephyra/issues/866)).

### Item detail screens and external ratings

`MovieViewModel`, `ShowViewModel`, `SeasonViewModel`, `EpisodeViewModel`, and `PersonViewModel` load their primary item and cast/crew concurrently inside `coroutineScope` ([#252](https://github.com/midasvo/ephyra/issues/252), [#262](https://github.com/midasvo/ephyra/issues/262), [#274](https://github.com/midasvo/ephyra/issues/274)). `MovieViewModel`, `ShowViewModel`, `SeasonViewModel`, and `EpisodeViewModel` manage freshness with `ReloadPolicy` and update played and favourite flags in place (`reloadPolicy.changedHere()`). In `ItemCatalog` (`MediaRepositoryImpl`), `getItem`, `getMovie`, `getShow`, `getSeason`, and `getEpisode` fall back to Room (`StoredItems`) for the current server when unreachable ([#281](https://github.com/midasvo/ephyra/issues/281), [#718](https://github.com/midasvo/ephyra/issues/718)); `ShowViewModel` and `SeasonViewModel` also use `offline = true` and `serverOrStoredList` for stored seasons and episodes.

`DetailSections` (`AppPreferences.detailSections()`) strips disabled metadata (`Movie.shownIn`, `Show.shownIn`, `Episode.shownIn`, `RelatedItemsRequest.shownIn`) before state emission ([#332](https://github.com/midasvo/ephyra/issues/332)). After the first frame (`AfterFirstFrame`), `MovieViewModel.loadRelated` and `ShowViewModel.loadRelated` launch `launchRelatedItems` (`ItemExtras`: local trailers/special features, item collections on movies, and similar items, gated by `ServerCapabilities`) and `ExternalRatingsLoader.load` ([#331](https://github.com/midasvo/ephyra/issues/331), [#769](https://github.com/midasvo/ephyra/issues/769)).

`ExternalRatingsLoader` keeps row height stable during loading via `ExternalRatingsState.Pending` when `ExternalRatings.mightHaveRatings` is true, and suppresses MDBList's Rotten Tomatoes chip when `criticRating` from Jellyfin is already shown (`rottenTomatoes = sections.criticRating && item.criticRating == null`). `ExternalRatingsService` coordinates `RatingsProvider` (`MdbListClient` calling `api.mdblist.com` for IMDb, Rotten Tomatoes, Metacritic, and Letterboxd using TMDB/IMDb/TVDB IDs) and `RatingsCache` (`FileRatingsCache` under `cacheDir/external_ratings`), deduplicating concurrent lookups per title and keeping 429/failure/invalid-key back-offs in memory ([#331](https://github.com/midasvo/ephyra/issues/331)).

On phone, `ItemButtonsBar` renders Play / Resume / Play from beginning / Shuffle (`onShuffleClick`), trailer menu, played toggle, favourite toggle, download/delete buttons (hiding server-only actions when `LocalServerStatus.current.confirmedUnreachable`), `VersionDialog` for multi-source items, and `DownloaderCard`. On TV, `ShowScreen` also triggers `ShowViewModel.loadThemeSong` when `tvThemeMusic` and `ServerCapabilities.themeSongs` are enabled ([#141](https://github.com/midasvo/ephyra/issues/141), [#769](https://github.com/midasvo/ephyra/issues/769)).

## Rules

- **R1, R2**: no Jellyfin SDK types or `JellyfinApi` outside `server/jellyfin/`. All catalog, list, and extras calls go through `ItemCatalog`, `ItemLists`, and `ItemExtras` (`MediaRepositoryImpl`) over `ItemPort`, `ItemListPort`, and `ItemExtrasPort` (`JellyfinCatalog`).
- **R4**: no production file outside `data/` imports `ServerDatabaseDao`. `MediaRepositoryImpl` reads offline items and stored libraries through `StoredItems` and `StoredItemLists`.
- **R9**: only the apps (`app/phone`, `app/tv`) depend on `data/` and `ratings/mdblist/`. `modes/film/` sees only `ExternalRatings` in `application/`.
- **R10**: `ItemId`, `ServerId`, `UserId`, and `MediaSourceId` are value classes (`Ids.kt`); never pass bare `String` or `java.util.UUID` ids outside `server/jellyfin/`.
- **Structured concurrency & test dispatchers**: concurrent `async` blocks in ViewModels must sit inside `coroutineScope { }` so failures stay inside `try/catch` instead of crashing `viewModelScope` (`HomeViewModel`, `ShowViewModel`, `SeasonViewModel`, `PersonViewModel`). `modes/film/` tests inject dispatchers (`loadDispatcher`, `defaultDispatcher`, `ioDispatcher`, `sectionsDispatcher`) so background work never outlives a test ([#809](https://github.com/midasvo/ephyra/issues/809)).
- **TV focus & no offline mode**: TV screens in `app/tv/.../ce/presentation/film/` restore focus via `FocusPosition` / `RestoreFocus` ([ADR 0003](../tv-research/adr/0003-focus-restore.md)) and omit offline banners and Room fallbacks ([ADR 0007](../tv-research/adr/0007-no-offline-on-tv.md)).

## Pitfalls

- **Bare `async` inside `viewModelScope.launch` crashes on network error.** Concurrent `async` blocks in `HomeViewModel`, `ShowViewModel`, `SeasonViewModel`, and `PersonViewModel` must stay wrapped in `coroutineScope { }` so a child failure is caught instead of cancelling `viewModelScope` and crashing the process.
- **Including `ItemKind.PHOTO` breaks `IndexedItemsPagingSource`.** `LibraryViewModel` leaves photos out of `HomeVideos`, `Mixed`, and `Folders` because every returned item must map to a supported `Item` or the indexed pager's total count and offsets drift ([#671](https://github.com/midasvo/ephyra/issues/671)).
- **Episodes omit `canDownload` unless `EpisodeField.CAN_DOWNLOAD` is requested.** `ShowViewModel` (`showEpisodeFields`) and `SeasonViewModel` (`seasonEpisodeFields`) explicitly request it; dropping that field silently disables episode/season downloads (`SeasonEpisodeFieldsTest`).
- **Room updates the current user before `ServerSession` switches.** `HomeViewModel` waits for `clientActsFor(userId)` and gates state emissions by `LoadGeneration`, while `HomeScreen`, `MediaScreen`, and `FavoritesScreen` apply `.shownTo(userId)` so the previous user's items never flash for a frame ([#810](https://github.com/midasvo/ephyra/issues/810), [#866](https://github.com/midasvo/ephyra/issues/866), [#872](https://github.com/midasvo/ephyra/issues/872)).
- **Replacing `LibraryViewModel.loadItemsIfNeeded()` with a screen `rememberSaveable` flag breaks process-death restoration.** Saved Compose state survives process death while the recreated ViewModel has empty `items`, leaving a spinner forever if `LoadKey` is bypassed ([#371](https://github.com/midasvo/ephyra/issues/371)).
- **`ExternalRatingsService` caches empty results on disk and keeps back-offs in memory only.** `FileRatingsCache` persists empty lists for `NotFound` or titles with no supported scores (`EMPTY_TTL_MS`), and `ExternalRatingsLoader` clears `loadedFor` only when `!source.canRequest(lookup)` so transient errors/429s/invalid keys can retry once allowed; `rejectedKey` and `blockedUntil` reset on process restart ([#331](https://github.com/midasvo/ephyra/issues/331)).
- **`LetterIndex` hides itself if counts disagree with `total`.** `LetterIndex.build` returns `null` when the 26 `nameLessThan` counts are non-monotonic or exceed `total`, and `LibraryViewModel` invalidates the cached index when the first page's `total` changes ([#135](https://github.com/midasvo/ephyra/issues/135), [#672](https://github.com/midasvo/ephyra/issues/672)).
